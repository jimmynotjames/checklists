Checklists that can be reset with a single tap to do again.

Never forget a crucial step again. Train a complex task by using a checklist until it's natural. 

Use for recurring checklists, like packing lists and shopping lists.

[Download the App!](https://itunes.apple.com/app/id1475724536)

## Feature List

* **Free app** (can donate inside the app if you like it!)
* Create checklists that can be checked off and reset to be used again.
* Can record notes for each checklist or checklist item.
* Can reorder checklists and checklist items arbitrarily (drag and drop style).
