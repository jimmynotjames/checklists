Build Notes.txt

To help me re-build the project after a long time away.

All commands are from project's root folder unless otherwise specified. 

Venv:
1. Make sure venv is there. Otherwise establish venv with these commands:
  python3 -m venv venv

2. Make sure to activate venv
  source source venv/bin/activate

3. Xcode Build Params - Go to checklists Target
  a. Signing & Capabilities -> Make sure there's a Signing Certificate provisioned and working.
  b. Swift version -> Consider updating

4. Clean Build Folder and Delete Derived Data
